# VV Audio

Комната для совместного прослушивания музыки с другом. Поддерживаются Spotify, SoundCloud, YouTube и свои аудиофайлы. Premium не нужен.

## Запуск для разработки

Нужен Node.js 20 или новее.

```
npm install
npm run dev
```

Откройте http://localhost:5173, заведите аккаунт и нажмите «Создать комнату». Ссылку для друга копирует кнопка «Позвать друга».

## Аккаунты и база данных

Войти в комнату можно только с аккаунтом (логин и пароль). Друг, открывший ссылку-приглашение, сначала регистрируется и сразу попадает в комнату.

Всё хранится в SQLite-файле `data/vv.db`. Отдельно ставить ничего не нужно: база встроена в Node.js.

- Аккаунты: пароли хранятся только в виде хеша scrypt. Сессия живёт 30 дней в cookie, недоступной из JavaScript.
- Комнаты: очередь, текущий трек и позиция сохраняются. После перезапуска сервера комната открывается на паузе с того же места.
- Чат: хранятся последние сообщения. Уведомления «зашёл / вышел» не сохраняются.
- «Мои комнаты» на главной странице: комнаты, где вы были. Крестик убирает комнату только из вашего списка.
- Избранное: сердечко у трека. Список личный, из него можно добавить трек в очередь.

После 10 неудачных попыток входа с одного адреса или на один логин вход блокируется на 15 минут.

Для резервной копии достаточно скопировать папку `data/`, когда сервер остановлен. Путь к базе можно поменять переменной окружения `DB_PATH`.

## Как позвать друга из интернета

1. Соберите приложение и запустите его на одном порту:
   ```
   npm run build
   npm start
   ```
   Приложение откроется на http://localhost:3001.
2. Откройте туннель на этот порт. Подойдёт любой из двух вариантов:
   - Cloudflare Tunnel (бесплатно, без регистрации): установите `cloudflared` и выполните `cloudflared tunnel --url http://localhost:3001`.
   - ngrok: `ngrok http 3001` (нужен бесплатный аккаунт).
3. Туннель выдаст публичный адрес вида `https://....trycloudflare.com`. Откройте комнату по этому адресу и скопируйте ссылку кнопкой «Скопировать ссылку».

## Источники

| Источник   | Как добавить                                                    | Ограничения                                                                                                                                       |
| ---------- | --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| Свои файлы | «Загрузить свой файл»: mp3, m4a, ogg, wav, mp4, webm, до 200 МБ | Файлы лежат в `uploads/` и не удаляются автоматически. У видео работает переключатель «Звук / Клип»                                               |
| YouTube    | Ссылка youtube.com/watch, youtu.be, music.youtube.com, shorts   | Видео с запретом встраивания пропускаются                                                                                                         |
| SoundCloud | Ссылка soundcloud.com/автор/трек                                | Если автор запретил встраивание, трек пропускается с сообщением                                                                                   |
| Spotify    | Ссылка open.spotify.com/track/...                               | Полный трек играет, только если слушатель вошёл в Spotify в этом же браузере. Иначе играет 30-секундное превью, и приложение показывает подсказку |

Spotify воспроизводится через официальный встраиваемый плеер (Embed iFrame API), а не через Web Playback SDK, которому нужен Premium. Музыка нигде не скачивается: все внешние источники играют через свои официальные плееры.

## Поиск по названию

В строке над очередью можно вставить ссылку, и трек сразу добавится, или ввести название: появятся варианты из подключённых источников, каждый добавляется кнопкой «+».

Поиск идёт только через официальные API, и каждому источнику нужен свой ключ. Скопируйте `.env.example` в `.env`, впишите те ключи, что есть, и перезапустите `npm run dev`. Источник без ключа просто не участвует в поиске, а добавление по ссылке работает всегда.

| Источник   | Что нужно                                                                                                                                                                          | Цена                                                                   |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| YouTube    | `YOUTUBE_API_KEY`: в [Google Cloud Console](https://console.cloud.google.com/) создайте проект, включите «YouTube Data API v3», затем «Credentials → Create credentials → API key» | Бесплатно, примерно 100 поисков в день                                 |
| SoundCloud | `SOUNDCLOUD_CLIENT_ID` и `SOUNDCLOUD_CLIENT_SECRET` с soundcloud.com/you/apps                                                                                                      | По документации SoundCloud для регистрации приложения нужен Artist Pro |
| Spotify    | `SPOTIFY_CLIENT_ID` и `SPOTIFY_CLIENT_SECRET` с [developer.spotify.com/dashboard](https://developer.spotify.com/dashboard)                                                         | С февраля 2026 владельцу приложения нужен Premium                      |

Файл `.env` не попадает в git. Не публикуйте ключи.

## Как работает синхронизация

- Сервер хранит состояние комнаты: очередь, текущий трек, играет ли музыка, позицию и время последнего изменения.
- Каждый клиент вычисляет смещение своих часов относительно сервера и сам считает, где сейчас должна быть позиция трека.
- Раз в 2 секунды клиент сверяет свой плеер с расчётной позицией. Если расхождение больше 0.3 с (файлы, YouTube) или 1 с (Spotify, SoundCloud), он перематывает.

## Структура

```
server/   Express + Socket.IO: комнаты, очередь, загрузка файлов, метаданные по ссылкам
  db.ts     схема SQLite и запросы
  auth.ts   регистрация, вход, сессии
shared/   типы событий и состояния, общие для сервера и клиента
client/   React + Vite
  src/players/   по одному адаптеру на источник, с общим интерфейсом
  src/sync.ts    сверка локального плеера с состоянием сервера
```
